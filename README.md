# TruxPort Website

Een moderne, responsive website voor een vrachtwagen transportbedrijf gebouwd met Vue.js 3 en TypeScript.

## 🚛 Over het Project

TruxPort is een professionele website voor een transportbedrijf dat gespecialiseerd is in vrachtwagen transport en logistieke diensten. De website biedt een complete online presentatie met alle benodigde pagina's voor een transportbedrijf.

## ✨ Features

- **Moderne Vue.js 3** met TypeScript
- **Responsive Design** - werkt perfect op alle apparaten
- **Vue Router** voor navigatie tussen pagina's
- **Professioneel Design** met moderne UI/UX
- **Contact Formulier** met validatie
- **SEO Vriendelijk** met meta tags

## 📄 Pagina's

1. **Home** - Hero sectie, features, statistieken en call-to-action
2. **Onze Diensten** - Overzicht van alle transportdiensten en prijzen
3. **Onze Vrachtwagens** - Wagenpark overzicht met specificaties
4. **Contact** - Contactformulier en bedrijfsinformatie
5. **Over Ons** - Bedrijfsverhaal, team en geschiedenis

## 🛠️ Technologieën

- **Vue.js 3** - Frontend framework
- **TypeScript** - Type safety
- **Vite** - Build tool en development server
- **Vue Router** - Client-side routing
- **CSS3** - Styling en responsive design

## 🚀 Installatie & Gebruik

### Vereisten
- Node.js (versie 16 of hoger)
- npm of yarn

### Installatie
```bash
# Dependencies installeren
npm install

# Development server starten
npm run dev

# Production build maken
npm run build

# Production build previewen
npm run preview
```

### Development Server
Na het starten van `npm run dev` is de website beschikbaar op:
- **Lokaal:** http://localhost:5173
- **Netwerk:** http://[jouw-ip]:5173
